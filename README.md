An exact interpreter for make.fun's tiny stack ISA: every opcode and trap exactly per spec — wrapping multiplication, unsigned division and comparison, masked shift counts, each trap's own exit code. `node main.ts` answers a set of 40 programs, `/input` in, `/output` out. MIT.
